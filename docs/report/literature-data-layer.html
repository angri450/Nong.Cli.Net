Nong 数据层 — 统一存储方案

1. 所有数据在一个地方

C:\Users\你的用户名\Documents\workplace\
  ├── Cache\
  │   └── nong.db              ← 唯一数据库（LiteDB）
  └── Output\                  ← 生成的文件（Word/PDF）

用 NONG_WORKPLACE 环境变量可以换位置。

删掉 workplace 文件夹就清空所有数据。备份就复制这个文件夹。

2. 数据库里有什么

集合存什么谁写入
papers文献（标题、作者、摘要、引用数、DOI、关键词）lit search --cache
documents注册过的 Word/PDF 文档（路径、SHA256、格式）word db-import
blocks一刀三流切出的文本块（段落、标题、表格）word db-import
formats排版指纹（字体、字号、页边距）word db-import
structures文档结构（章节、表格位置）word db-import
assets提取的图片（二进制 + 尺寸）word db-import
outputs生成文件的路径记录各生成命令

3. 命令速查

命令说明
lit search --cache搜外文论文，直接写入 papers 集合
lit cache-stats看库里有多少论文
lit cache-query --min-year 2020从 papers 集合筛选
lit word --template tpl.docx从 papers 拿数据填 Word 模板
lit cache-export --limit 5导出精简 Markdown 喂 Claude
word db-import slicedir docx把一刀三流的输出导入 DB
word db-list看库里有哪些文档
word db-blocks doc-id查某个文档的文本块
word db-images doc-id查某个文档的图片

4. 实测验证

lit search --query "zeolite slow release" --cache
  → nong.db: papers 集合 +5

lit cache-stats
  → "5 papers cached, 5 with DOI"

lit cache-query --min-year 2005
  → 返回匹配论文的标题/作者/引用数

word dissect doc.docx -o sliced/
word db-import sliced/ doc.docx
  → nong.db: documents +1, blocks +6, formats +1

word db-blocks <id>
  → 返回文本块列表
