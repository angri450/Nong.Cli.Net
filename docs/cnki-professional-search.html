来源：CNKI 官方帮助手册 1.1.3 专业检索，2026-06-14 抓取存档。

专业检索面向图书情报专业人员查新、信息分析等工作，使用逻辑运算符和关键词构造检索式。

2. 匹配运算符

符号功能适用字段Nong 支持
= = 'str' 检索与str相等的记录 KY、AU、FI、RP、JN、AF、FU、CLC、SN、CN、IB、CF OK
= = 'str' 包含完整str的记录 TI、AB、FT、RF OK
% % 'str' 包含完整str的记录 KY、AU、FI、RP、JN、FU NEW v4.3
% % 'str' 包含str及str分词的记录 TI、AB、FT、RF NEW v4.3
%= %= 'str' 相关匹配str的记录 SU NEW v4.3

示例

KY = 数据挖掘                          — 精确检索关键词含"数据挖掘"
AB % 计算机教学                        — 模糊检索摘要含"计算机"和"教学"的文献
SU %= 大数据                           — 主题与"大数据"相关

3. 比较运算符

符号功能适用字段Nong 支持
BETWEENBETWEEN ('str1', 'str2')YE、CFOK

示例

YE BETWEEN ('2010', '2018')            — 2010至2018年
CF > 0                                 — 被引频次不为0

4. 逻辑运算符

符号功能Nong 支持
AND逻辑"与"NEW v4.3
OR逻辑"或"NEW v4.3
NOT逻辑"非"NEW v4.3

示例

KY = '知识管理' AND AU = '邱均平'      — 邱均平发表的关键词含知识管理的文章
SU %= '知识管理' OR TKA = '知识管理'    — 主题相关或篇关摘含知识管理
TI = '大数据' NOT TI = '大数据集'       — 篇名含大数据但不是大数据集
AU = '钱伟长' AND (AF ='清华大学' OR AF ='上海大学')

提示：AND、OR、NOT 前后需有空格。用英文半角圆括号确定优先级。

5. 复合运算符

符号功能Nong 支持
*'str1 * str2' 同时包含str1和str2OK
+'str1 + str2' 包含str1或str2OK
-'str1 - str2' 包含str1但不含str2OK

示例

FT = '催化剂' * '反应率'               — 全文同时含催化剂和反应率
KY = '铝合金' + '钛合金'               — 关键词为铝合金或钛合金
KY = '大数据' - '人工智能'             — 关键词含大数据但不含人工智能

6. 位置描述符

符号功能适用字段Nong 支持
#'STR1 # STR2' 同一句中TI、AB、FTNEW v4.3
%'STR1 % STR2' 同一句中，STR1在前TI、AB、FTNEW v4.3
/NEAR N同句，相隔不超过N个字词TI、AB、FTNEW v4.3
/PREV NSTR1在STR2前不超过N个字词TI、AB、FTNEW v4.3
/AFT NSTR1在STR2后且超过N个字词TI、AB、FTNEW v4.3
/SEN N同段中，句子序号差不大于NTI、AB、FTNEW v4.3
/PRG N相隔不超过N段TI、AB、FTNEW v4.3
$ N关键词最少出现N次FTNEW v4.3

示例

FT = '人工智能 # 推荐算法'             — 某句中同时出现"人工智能"和"推荐算法"
FT = '人工智能 % 推荐算法'             — 同句中出现且"人工智能"在前
FT = '人工智能 /NEAR 10 推荐算法'      — 同句中两词间隔不超过10个字词
FT = '人工智能 /PREV 10 推荐算法'      — "人工智能"在"推荐算法"前，间隔不超过10字词
FT = '人工智能 /AFT 10 推荐算法'       — "人工智能"在"推荐算法"后且超过10字词
FT = '人工智能 /SEN 1 推荐算法'        — 同段中两词所在句子间隔不超过1句
FT = '出版 /PRG 5 法规'                — 含"出版"和"法规"，所在段落间隔不超过5段
FT = '大数据 $5'                       — 全文中"大数据"出现至少5次

注意：位置描述符需用一组英文半角单引号将检索值及其运算符括起。仅限于两个值之间的限定，不适用于连接多值。

7. 各平台管线说明

所有位置描述符和高级运算符仅在本机过滤层生效。各搜索平台 API 收到的是纯关键词：

平台收到什么本地过滤能力
OpenAlex关键词字符串 (空格分隔)全部 DSL 运算符
Crossref关键词字符串全部 DSL 运算符
AMiner关键词字符串全部 DSL 运算符
秘塔 (Metaso)关键词字符串全部 DSL 运算符
UnpaywallDOI 精确查询DOI 精确匹配

设计原则：宽搜 + 精滤。搜索引擎尽量多搜（宽搜），拿回来后本机精确匹配 DSL 条件（精滤）。搜索引擎本身不懂 /NEAR、$N 等 DSL 运算符。
