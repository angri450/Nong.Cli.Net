# 2026-06-14 — v4.3.0 文献检索管线全面重写

## 背景

CNKI 专业检索语法提供 20+ 运算符和字段限定，但当前管线只支持 `* + - ()` 三种基础运算符。AMiner 和 Metaso 的功能远远超出当前的"关键词拼串"用法——AMiner 有 7 个免费 REST 端点、Metaso 有搜索/阅读/RAG 三大功能模块。

用户要求：拆包——外文搜索管线 (Lit)、AMiner 独立包、Metaso 独立包；CLI 路由；Toolkit skill.md 编排。

## 新 CNKI 运算符支持 (22项全部验证通过)

基础: `*` `+` `-` `AND` `OR` `NOT` `()`
位置: `#` `%`(引号内) `/NEAR N` `/PREV N` `/AFT N` `/SEN N` `/PRG N`
修饰: `% 'str'` `%= 'str'` `/SUB N` `$ N` `BETWEEN`

## 平台土话翻译

```
DSL: AU='钱伟长' AND AF='清华大学' AND YE BETWEEN(2010,2020) AND CF >= 3
  ↓ StructuredQuery: authors=[钱伟长] institutions=[清华大学] yearFrom=2010 yearTo=2020 minCitations=3
  ↓
OpenAlex → filter=authorships.author.display_name.search:钱伟长,
                  publication_year:>2009,publication_year:<2021,
                  cited_by_count:>2
Crossref → query.author=钱伟长&filter=from-pub-date:2010,until-pub-date:2020
```

## 已知限制

- `CF >= N` 语法不支持，需用 `CF BETWEEN(N,9999)` 替代（`>` `<` 为 Unsupported token）
- AMiner 免费 API 不支持字段级过滤，仅 keyword 搜索
- Metaso reader 的 `text/plain` Accept header 输出格式待实际 API 验证
- Metaso SSE streaming 在 System.CommandLine handler 中受限于 `Console.Write`，非 JSON 模式下交互体验一般
